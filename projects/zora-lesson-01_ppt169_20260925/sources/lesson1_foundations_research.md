## Research Brief

- 主题与成果：为 Zora Studio 第一节课「认识 AI · 环境搭建」补充必要事实，支持中文教学 PPT 与每页逐字稿；本文件不承担页序、版式或产品选型。
- 提供材料基线：`huyml-rebuild/src/components/course-syllabus-data.ts` 中第 1 天上午 09:30–12:30 课程；包含 AI 能力、LLM、Token、上下文、幻觉、模型类别、终端与运行环境、编程助手、API Key、结构化提示词、安全与资料整理报告跟练。该课程范围与产出要求保持不变。
- 已知受众与意图：第一节基础教学，帮助学员搭建 AI 工作台并完成首个自动化任务；不预设学员已有命令行经验。
- 声明缺口：① Token／上下文／幻觉边界；② 模型能力维度与开放许可；③ 终端、Node.js、LTS 安装验证；④ API Key 与计费原则；⑤ 编程助手权限与人工审阅。
- 检索边界：仅采用已打开的官方或标准制定组织页面，核查日期 2026-09-25；不比较模型排名、不承诺价格、不指定课上必用产品与版本；不研究图片。

## Token、上下文与事实边界

- [F001] Token 是模型处理输入、输出的计量单位；文本会被切分成 Token，一个 Token 可以是字符、完整词或词的一部分，不能把 Token 数直接当成中文字数。
- [F002] 模型一次可处理的内容存在 Token 上限；上下文窗口限制输入与输出的合计容量，使用时还需核对所选模型分别标出的输入、输出限制。
- [F003] 大语言模型可能生成事实错误的内容；检索依据可改善事实性，但输出仍需要与任务风险相称的人工核查和测试。

## 模型能力与开放许可

- [F004] 多模态输入与推理能力可以同时存在于同一个模型；能接收图片、音频或视频，不代表能生成这些模态。
- [F005] 按 OSI《Open Source AI Definition 1.0》，开放 AI 需提供使用、研究、修改、分享的自由，并具备相应的数据信息、代码与参数；仅能下载权重，不足以据此认定其满足该定义。

## 终端、运行环境与安装验证

- [F006] Windows Terminal 是承载命令行 Shell 的应用，可运行 PowerShell、Command Prompt，以及通过 WSL 使用的 bash；终端窗口和执行命令的 Shell 是不同层次。
- [F007] macOS 的 Terminal 应用提供命令行界面；用户输入的命令或脚本由 Shell 执行，用来完成电脑上的任务。
- [F008] Node.js 是跨平台的 JavaScript 运行环境，可以在浏览器之外运行 JavaScript。
- [F009] Node.js 和 npm 可通过版本管理器或安装包安装；npm 官方文档建议 macOS、Windows 安装包用户选择标为 LTS 的版本，并用 node -v 与 npm -v 检查安装及版本。

## API Key 与计费原则

- [F010] 以 Gemini API 为例，API Key 应像密码一样保管：不提交到 Git，不硬编码进生产网页或手机端；泄漏后应更换并停用泄漏密钥，同时检查用量和账单。
- [F011] 以 Gemini API 为例，付费调用按使用量计费，输入与输出 Token 分别列价；模型、服务档位、缓存或附加工具可能影响费用，不能用“问了一次”推断固定金额。

## 编程助手权限与人工审阅

- [F012] 以 Claude Code 的 Manual 模式为例，读取、写文件和执行命令受权限边界约束，修改与有影响的命令会请求批准；用户仍需在批准前审阅建议的代码和命令。

## 事实适用边界与材料冲突

- 无实质材料冲突。课程原文只列出主题，未给出需纠正的数值或产品结论。
- [F004][F005] 共同支持一个教学解释：能力与开放方式是不同观察维度；课程列出的“对话、推理、多模态、开源”不宜讲成四个互斥类别。此句为对已核查事实的教学归纳，不是额外模型排名。
- [F001] 不把英文 Token 粗估比例用于中文；本研究未采用固定的中文字符换算比例。
- [F005] 开放权重、开源代码、可商用等具体权限，应按选定模型的实际许可证逐项核对；本研究未为任何具体模型作许可结论。
- [F010][F011][F012] 产品只是有据可查的技术示例，不代表课程必须选用这些产品，也不把单一厂商的全部细则外推至所有平台。
- 本轮不确定项为 0 个已声明事实缺口；具体编程助手安装命令、账户可用地区、实时价格与界面步骤待主任务确定产品后再核查。数据隐私条款没有展开成跨厂商保证。
